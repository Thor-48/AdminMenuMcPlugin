# AnonymByInvis

AnonymByInvis is a lightweight Minecraft plugin that automatically hides a player's name while they are invisible.

## Features

* Automatically hides your name in the player tab while invisible.
* Restores your normal name when invisibility ends.
* Hides the invisible killer's name in death messages.
* Automatically updates when invisibility changes.
* Simple and lightweight.

## Usage

Simply install the plugin on your Bukkit, Spigot, or Paper server.

When a player has the **Invisibility** effect, their name is automatically hidden. Once the effect ends, their normal name is restored.

## Command

### `/uwu`

Displays the plugin's built-in message.
